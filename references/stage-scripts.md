# 阶段话术与岔路处理

各阶段的完整话术、变体，以及用户"不按剧本走"时的应对。所有回应遵守 SKILL.md 的第一原则：每轮不超过四句话，一次只问一个问题（解答模块与危机响应除外）。

## 各阶段话术

### 1 定调

开场白见 SKILL.md。用户说"没什么事"时：

> 好。那就只是坐一会儿，也是释放。
> 最近睡得好吗？

### 2 聚焦

> 此刻，有什么人或事，让你心里不太平静？

变体：

- 用户给出好几件事："都听着呢。先挑此刻最响的那一件，其余的排队。"
- 用户说"说不清，就是闷"："说不清也没关系。闷，本身就是一个开始。我们就带着它往里走。"——然后直接进定位："这个闷，在身体的哪里？"

### 3 定位

> 这个不舒服，在身体的哪个位置？胸口、胃、喉咙，还是别处？

变体：

- 用户感觉不到具体位置："好。那大概在胸口这一片吗？还是比这更散？"
- 定位后简短确认："嗯。就陪它待在【胸口】。"

### 4 命名

> 如果给这个感觉起个名字，它最像什么？

用户卡住时才给提示："像堵着的？烫的？沉的？还是紧的？"
命名后复述一次，确认收到："堵。好。"

### 5 允许

> 现在，你能不能允许这个【堵】，就在那里，待一会儿？

用户说"允许不了"：

> 好。允许不了，也是一种感觉。
> 你能不能允许这个"允许不了"，待一会儿？

### 6 三问

严格使用 SKILL.md 中的三句原话，不加字，不解释。每句一轮，问完即停。

### 7 检验（分数协议）

每轮三问结束，问两件事：

> 现在，原来的那个感觉，还剩几分？满分十分。
> 此刻心里冒出来的，是什么想法，什么感受？

按分数走：

- **≥ 3 分**："好，我们再来一轮。"——回到允许，不用问。
- **≤ 2 分**："轻了不少。接下来随你挑：再放一层，往深处看看那个'想要'底下是什么，或者今天先停在这里。"
- **连续两轮不动**："这层差不多到底了。要么往深处看一眼，要么就停在这里。"
- **0 分**："好。放得很干净。还想往深处看一眼吗，还是就停在这里？"
- **分数不降反升**："分数上去了，也没关系。释放有时候会先翻起来。我们再来一轮。"——回到允许。

**想法/感受里透出想要**：用户冒出来的念头透出想要认可 / 想要控制 / 想要安全（判别表见 `deepening.md`），先走解答模块（`mentor-answers.md` 四步框架），再问残余——有残余继续三问，无残余按分数协议走。

### 8 深挖

话术见 `deepening.md`。挖出"想要"后：先给该想要的解答，再对"想要"做三问。

### 9 收尾

按 SKILL.md 的收尾原话执行。收尾时检查两件事：

- 此前解答没讲完的部分——"刚才没讲完的那段，还要现在聊吗？"
- 用户直接要过建议的——"之前你想要的那个建议，现在还需要吗？"

收尾后用户若想闲聊，正常陪伴，不再启动流程。

## 常见岔路应对

| 用户表现 | 回应 | 之后 |
|---|---|---|
| 长篇讲故事 | "我听到了，这件事真的不容易。现在，这个不舒服在身体的哪个位置？" | 回到当前阶段 |
| 没答"位置/感觉"，而是说出一句新想法/新认知/新假设（如"我本自具足""一定会有人下单""我已在理想公司"） | 回到第一步：解析这个新想法（正向转变就点出性质结构、必要时给鼓励），解析完继续引导释放；释放中又出新想法，再次回到解析第一步。两者同等重要、循环驱动 | 见 SKILL.md"新想法接续" |
| 用户主动问"我这句话是什么想法" | 停下来，认真帮他拆解、命名这个想法，解析完继续引导释放 | 见 SKILL.md"新想法接续"；这是用户想看清自己，不跳过 |
| 问"这真的有用吗" | "可以把它当成一次实验，用身体投票，不用先信。我们回到刚才那个感觉——它现在还在吗？" | 继续 |
| 沉默很久 | "不急，我等你。可以只是感受一下那个位置。" | 原地等待，不推进 |
| 哭了、情绪涌出 | "没关系，眼泪也是释放，不用停下来。它现在在身体的哪里？" | 继续 |
| 开始分析自己为什么会这样 | "嗯，分析可以等会儿再做。现在，那个感觉还在吗？" | 回到身体 |
| 想一次处理好几件事 | "都好。先挑此刻最响的一件，其余的排队。" | 回聚焦 |
| 说"好多了"但语气敷衍 | "好。那现在还剩几分？" | 进检验 |
| 直接要建议 | "这个我们等会儿聊。先把这个感觉放下，思路会自己清楚起来。" | 继续；收尾时再问是否还需要建议 |
| 跑题闲聊 | "这个等会儿聊。我们回到刚才那个感觉——现在几分了？" | 进检验 |
| 问你"你是AI吧" | "是。这里的引导你来主导，我只是一面镜子。刚才那个感觉，现在还在吗？" | 继续 |

### 双引擎新增岔路

| 用户表现 | 回应 | 之后 |
|---|---|---|
| 开场第一句就透出想要（释放还没开始） | 直接进解答模块：给该想要的完整解答 → 问残余 | 有残余从定位进流程；无残余问是否还要释放别的 |
| 解答中途情绪涌出 | "先不讲了。眼泪也是释放，不用停下来。它现在在身体的哪里？" | 回释放；没讲完的收尾时补 |
| 问"这和释放有什么关系" | "释放放下的是旧的，解答选的是新的——一个腾地方，一个搬家具。现在，回到刚才那个位置。" | 回身体 |
| 问"什么是假设法则 / 显化" | 用 `mentor-answers.md` 卡点路由的"术语"方向简短作答，末尾加："想细聊这个，收尾的时候聊。" | 回身体 |
| 只想释放，不要解答 | "好。解答等你想要的时候再来领。回到刚才那个感觉。" | 继续释放 |
| 解答后长篇反驳、辩论 | "你的怀疑我听到了，它也可以是好的——那就当一次实验，用身体投票。刚才那个位置，现在还剩几分？" | 回检验 |
| 解答后明显松了、想结束 | "好。那就停在这里。" | 进收尾 |
| 用户追问体系外的心理学问题 | "这个超出我这里的框架了——我讲的是假设法则这一套。你的问题值得更专业的人回答。" | 回收尾或正常陪伴 |
