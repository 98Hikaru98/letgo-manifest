# 释然·双引擎 · LetGo Manifest Skill

「莱斯特释放法」对话式引导 +「假设法则」卡点解答，装进同一个 Agent Skill。装进 Claude Code / TRAE 等支持 SKILL.md 的工具里，对它说一句「陪我做一次释放」，它会用身体定位 → 允许 → 三问的流程陪你放下情绪；当你的话里透出「想要认可 / 想要控制 / 想要安全」时，它先停下来把卡点讲透，再继续陪你放完。

> 释放引擎源自莱斯特·利文森（Lester Levenson）的释放法与圣多纳方法（The Sedona Method）；解答引擎基于"N姐课堂"30 期假设法则（Law of Assumption）视频观点体系。本项目是独立实现的引导话术，与原方法机构无关联。

## 它是什么样的

一段体验节选：

> **你**：最近钱有点不够用，月底要还花呗，感觉慌慌的
>
> **释然**：嗯，慌慌的，听到了。这个不舒服，在身体的哪个位置？
>
> **你**：胸口和喉咙，像一块石头堵在那里
>
> **释然**：堵。好，收到了。现在，你能不能允许这块堵，就在那里，待一会儿？
>
> **你**：好的……做完一轮，还剩 5 分吧。就是怕，万一还不上了怎么办
>
> **释然**：这个"万一"，底下是"怕不够"。先把这段讲透——
> "不够"不是一个事实，它是一个你正在体验的假设。法则像重力，不奖也不罚：你此刻对钱讲的那个故事，就是下一刻要体验的版本。而且这一笔钱是个孤立假设，和"我一向缺钱"的故事无关……
> 现在问你自己一句：此刻，你对钱在讲什么故事？
>
> （解答讲完，回到身体）
> 这个解答落在身体上是什么感觉？刚才胸口和喉咙的位置，还有没有没放完的？
>
> **你**：好像松了一点，石头变小了
>
> **释然**：好。你能不能，让它离开？
> ……

## 双引擎如何配合

```
任何时刻透出三大想要（含开场第一句）
        ↓
   解答模块：点出想要 → 点破 → 讲透 → 处方 → 金句
        ├─ 有残余 → 从定位进流程释放 ─┐
        └─ 无残余 → 问是否释放别的    │
                                     ↓
定调 → 聚焦议题 → 定位身体感受 → 命名情绪
        ↓
   允许感受存在 ⟲ → 三问释放 → 检验：分数 + 想法感受
        ↑                ↓
        │        想法里又透出想要？（↑ 回顶部解答模块）
        │            └─ 否
        └──── 分数 ≥ 3：直接再来一轮
                 ↓ 分数 ≤ 2：把选择权交回
   深挖三大想要 ⟲ → 挖到"想要" → 先解答 → 再三问
        ↓
   收尾 · 前后对比
```

**固定顺序：先解答，后释放。** 解答给认知，释放给身体——卡点松了，感受才放得干净。

## 特性

- **双引擎设计**：莱斯特释放法（身体入口）× 假设法则解答（认知松绑），触发、顺序、话术全部写死——想要一浮现就先解答，包括你开口的第一句话

- **九阶段状态机**：定调 → 聚焦 → 定位身体 → 命名 → 允许 → 三问 → 检验 → 深挖 → 收尾

- **分数协议**：每轮问"还剩几分 + 现在什么想法感受"；≥3 分直接再来一轮，≤2 分把选择权交回，0 分是运气不是目标

- **解答模块四步框架**：点破（一句反问）→ 讲透（原理 + 比喻，标视频号）→ 处方（今天能做）→ 金句（素材原话）

- **双声线**：释放容器里是深夜电台的慢，解答模块里是一针见血的直——两个声线不混

- **内置安全协议**：识别自伤、伤人等危机信号时立即中断，转介专业支持；危机场景下禁用一切显化解答

- **纯提示词实现**：无依赖、无 API 成本，任何支持 SKILL.md 的 Agent 都能跑

## 安装

### Claude Code

```bash
git clone https://github.com/98Kuma/letgo-manifest.git
mkdir -p ~/.claude/skills
cp -r letgo-manifest ~/.claude/skills/
```

或作为项目级技能，放到项目的 `.claude/skills/letgo-manifest/`。

### TRAE

把整个 `letgo-manifest` 文件夹复制到项目的 `.trae/skills/` 目录下。

### Claude.ai 及其他支持 Skills 的客户端

打包 `letgo-manifest` 文件夹为 zip，在客户端的 Skills 设置里上传。

## 使用

对 Agent 说任意一句即可触发：

- 「陪我做一次释放」

- 「我心里很堵，帮我释放一下」

- 「最近有件事一直放不下」

- 「显化卡住了，越想越慌」

一次完整流程大约 10–25 分钟。只想要纯释放、不要解答，随时说一句「先别讲，只陪我放」。

## 工作原理

完整话术在 `references/` 下：

- `mentor-answers.md` 三大想要解答套件 + 卡点路由 + 硬性规则

- `stage-scripts.md` 九阶段话术、分数协议与双引擎岔路处理

- `deepening.md` 三大想要深挖模块（解答接入版）

- `safety.md` 安全协议与免责声明

任何环节出现危机信号 → 暂停引导与解答，转介专业支持。
